## 問い

コーディングでは、作業中のファイル、直近のエラー、計画、直近のやりとりは正確なまま必要で、記憶では置き換えられない。置き換えられるのは、作業が長くなるほど増え続ける古い履歴だけである。今の dsh は文脈があふれそうになると古い履歴を要約して捨てるが、要約では細部（昔のエラー文、試してダメだった理由）が消える。

**文脈を 32k に保ったまま、要約に記憶を足すと、作業の成功率が保たれ、同じ失敗の繰り返しが減るか。さらに、大きな文脈（131k）と同じだけ作業をこなせるか。**
