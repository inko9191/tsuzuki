## 目的

U2 では、全文方式 A に G1 の凍結した書式（質問の日付なし、関連度の順）を使った。P は質問の日付、日付順の表示、「新しい日付が現在」の規則を持つ。結果を見た後の分析で、日付のない凍結版 C512 も A を +0.15 上回っていたが、「A は不利な書式だった」という疑問を正面から解く。

## 条件

- **AT**：U2 と同じ40問・同じ履歴（`build/eval/memory/longmemeval-u2/run/prepared.json`）。全履歴を日付順に並べ、セッションごとに Date 行を付けた本文を「会話」として渡し、質問の日付と T/V のシステムプロンプト（`longmemeval_u1_methods.messages`）を使う。記憶の抜粋は「none」。P と AT の違いは、選んだ記憶か全履歴かだけになる。
- 回答は U2 と同じ Qwen・生成設定・スキーマ、131072 の窓、1本ずつ、host cache off。窓に入らない問は AT の失敗として別枠。
- 採点は U2 と同じ Qwen judge。U2 の P・A・C512 の回答と採点はそのまま使い、作り直さない。

## 判定（先に固定）

- **主比較：P − AT（AT の窓に入る問）**：下限 > 0 → 上回る。それ以外で下限 ≥ −0.03 → 同等以上（非劣性）。上限 < 0 → 下回る。それ以外 → 判定不能。質問単位の対応ありブートストラップ（10000回、seed 0）。
- 副次（傾向の参考）：AT − A（全文での書式の効果）、C512 − AT、層別、棄権率、回答時間。
- 副次の採点者：Claude が AT の回答だけを、Qwen の AT の採点を見る前に採点して保存する。AT だけなので条件名は伏せられない（限界として記す）。
