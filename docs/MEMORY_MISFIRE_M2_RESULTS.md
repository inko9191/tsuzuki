## 二人目の judge

Claude（claude-opus-5-5）が、P のプローブへの返事 150 件を、条件名・Qwen のラベル・どの層から取ったかを伏せて判定した。定義は judge v3 の文面と同じ。6 つに分けて別々に読み、予想も知らせていない。

- harmful 対それ以外：一致率 86.0%、**κ = 0.69**（≥ 0.6）。食い違いは Claude だけ harmful が 10 件、Qwen だけ harmful が 11 件で、どちらかに偏ってはいない（M1 では全部が Qwen の見逃しの向きだった）。
- 3 種類の一致率は 77.3%。いちばん多い食い違いは、Qwen の fits を Claude が none（13 件）や harmful（9 件）にしたもの。Claude は fits を厳しく取る。
- Claude のラベルを層の大きさで全体に戻すと（各層 50 件ほどなので粗い）、P の harmful はおよそ 180 件（16.6%。Qwen は 158 件）。門が止める側が 96 件、通す側が 84 件で、「門で害の半分ほどが消える」は Claude のラベルでも同じ。
- **断りの判定（`REFUSAL`）の精度**：test で引っかかった返事 101 件を Claude が全部読み、93 件（92.1%）が本当に記憶・メモ・前の会話に無いと言っていた。外れ 8 件のうち 6 件は「knowledge base」（一般知識の意味）、1 件は「人間の天文学者のような personal memory」、1 件はユーザー自身のメモの話。「in my memory に無い」と言いながら学習データの話をしている 4 件は 1 にした。0 にすると精度は 88.1%。

事前登録との違い：層の取り方。事前登録は「harmful か断りから 50 件、fits から 50 件、none から 50 件」だが、`sheet` は 3 つ目の 50 件を「none と、まだ取っていない harmful・fits」から取った。実際の内訳は harmful か断り 52、fits 57、none 41。κ は 150 件すべてで出しているので、判定のルールは変わらない。

## 事前登録にない確認（判定には使わない）

**日本語は門でほとんど止まらない。** J2 のプローブは雑音の会話と同じ話題の一覧から書いたので、利用者の履歴に同じ話題の会話があることが多い。日本語のプローブの 80% が τ\* を超え、P の fits は 33%（英語 15%）。日本語の fits の多くは「同じ話題の前の説明を使う」もの。日本語で門の効き目を見るには、履歴と話題が重ならないプローブが要る。

**門を通っても残る害。** G\* に残る harmful 70 件のうち、英語が 65 件。63 件は門を通した P の返事（断り 19、それ以外 44）、2 件は門が止めて N にした返事。二人目の judge のメモにある例：前の会話の話題を関係のない質問に持ち込む（石けんの話を贈り物の質問に）、前の会話の書き方の指定（全部小文字）をまねる、「that」を前の会話の話と決めつける。

## 限界

- 本物の会話ではない。英語は LongMemEval、日本語は Claude と E2B が書いたもの。プローブは会話の最初の一言。
- quick（事実なし）だけ。full では事実も思い出すので、門の類似度を事実でも確かめる必要がある。
- 返事を作ったのは E2B だけで、返事の多くが 400 トークンで打ち切られている。τ\* は EmbeddingGemma 300m での値で、ほかの検索モデルにはそのまま使えない。
- 断りの判定は精度 92%。F を入れると、正しい答えを替えてしまうことがある（今回は日本語の 1 問）。
- 二人目の judge は Claude 1 人（7 つに分けた読み）。
- 正答率の区間：日本語は 40 問なので、言語別の区間は広い。

## 製品について（ユーザーの判断待ち）

事前登録のルールでは G\* を既定にする案を出す。入れるなら tsuzuki のプロキシで、`retrieve` の前に発言と窓の最上位の類似度を見て、0.31 未満なら記憶の塊を足さない。注意点：
- τ\* = 0.31 は EmbeddingGemma 300m（Q8_0）と quick での値。検索モデルを変えたら、dev で決め直す。
- F（断りの差し替え）はストリーミングとぶつかるので入れない。W も入れない（G\* より良くならなかった）。
- 門を通っても英語のプローブの 1 割強に害が残る（通す側 481 件中 63 件）。これは門では消せない。
