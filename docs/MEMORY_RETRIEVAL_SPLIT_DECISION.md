# 分割・推論の判断：現行分割を維持する（b）

2026-10-12。ステージ1・2・2bとCCのレビュー結果を確認した後の判断。
分割や既存結果は書き換えず、未計測のステージ3以降に向けて報告・解釈の方針を追加する。
機械可読な記録は [inference-policy.json](../results/eval/memory/inference-policy.json)。

## 選択と理由

**(b)を採る。** 開発用1233問・本番用302問の質問単位の分割を維持する。
10会話すべてが両分割に含まれ、本番用は会話単位では独立していない。
この評価が測るのは「同じ10会話に対し、設定調整に使わなかった質問でどの程度根拠を拾えるか」である。
新しい会話・人物・話題への汎化性能とは呼ばない。

理由は次のとおり。

1. 今回は全文を記憶した会話から質問の根拠を探す第一段階であり、上記の限定した問いにも用途がある。
   共通の検索本文を使うことはこの問いの条件だが、開発用と本番用の質問や根拠には関連が残る。
2. 全10会話の開発質問と、分割前の全問ベンチマークは既に評価済み。
   今から会話単位へ切り直しても「一度も調整に使わなかった会話」は作れず、過去の情報への適応を取り消せない。
   10-foldの会話交差検証も、既に全会話の結果を見て設計した方法の完全に独立な検証にはならない。
3. 10会話だけを一度の会話分割にすると検証側の会話数がさらに小さくなる。
   会話交差検証は別の汎化評価として価値があるが、設定選択もfold内に閉じた手順に設計し直す必要がある。
   今回の本番用質問を守りながら、まず探索的な手法比較を完了する方を選ぶ。

未知会話への効果を主張する段階では、今回と別の未使用会話を用意し、会話分割と設定選択を結果を見る前に固定する。
会話ブートストラップを足しても、分割の非独立性や設計時の既存結果への接触が解消するわけではない。

## p2の扱い

既存レビューの開発用 `p2 − t1`、主指標 `recall@T512`：

| 平均差 | 質問単位95%区間 | 会話単位95%区間 | 改善／悪化／同点 | 両側の正確な符号検定 |
|---:|---|---|---|---:|
| +0.0213 | [+0.0037, +0.0384] | [−0.0058, +0.0463] | 7 / 3 / 0 会話 | p = 0.34375 |

質問単位の区間だけを根拠に、p2の改善が会話をまたいで確かだとは言わない。
会話単位の区間は0を含み、符号検定も改善方向が一貫しているという強い証拠を示していない。
これは「改善がない」という証明でもない。10会話では区間も検定の分解能も限られる。

ステージ2・2bのp2選択は、元の事前登録に従った**開発上の暫定選択**として残す。
新しい結果を見てからt1へ戻したり、採用閾値を変えたりしない。
主指標、候補、生成設定、同点処理、質問単位CIを使う既存の選択規則は維持する。
この選択規則は探索的な候補絞り込みであり、統計的に確証された改善を保証する手続きとは扱わない。

## 今後の報告方法を固定する

- 差の点推定は従来と同じ質問macro平均。会話を同じ重みにした平均へ黙って変えない。
- すべての事前登録候補とステージ基準の対応比較を報告する。選ばれた候補や有利な区間だけを示さない。
- 質問単位の対応ありブートストラップ95%区間は参考として残す。
- 主要な不確実性の表示は会話単位の対応ありブートストラップ95%区間。
  会話IDを復元抽出し、各抽出会話に属する質問をまとめて保持する。
  各標本は差の合計を質問数の合計で割り、元の質問macro平均と対応させる。
  回数10000、seed 0、percentile区間。会話IDを昇順にして乱数に対応付ける。
- 各会話内の平均差、質問数、改善／悪化／同点数も記載する。
  符号検定は会話内平均差の正負を使う正確な両側二項検定、帰無仮説は正負の確率が各1/2。
  厳密に差0の会話は検定から除き、同点数と有効会話数を報告する。
  式は `min(1, 2 * sum(comb(n, j), j=0..min(wins, losses)) / 2**n)`。
  [NISTの符号検定の説明](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/signtest.htm)に従う。
- 会話単位区間と符号検定は、差の大きさと方向の一貫性をそれぞれ示す。検定対象を同一視しない。
  会話間の独立性を仮定しても、10会話からの限定的な分析である。
- 複数候補を探索・選択した結果であり、区間は同時区間ではなく、p値も多重比較調整していない。
  この段階で探索候補の有意性や一般的優越性を断定しない。
- 本番用は設定選択後に、選んだ1設定だけを測る。絶対Recallには会話単位区間を添える。
  対応する本番用の比較相手が未計測なら符号検定は「対象なし」とし、そのためだけに別設定を追加計測しない。
- 各最終報告に「本番用は会話単位で独立でない」「過去の全問評価と重複する」を明記する。

## 事前性と既存生成物

ステージ2の結果とCCの会話区間は本判断より前に既知。これらに対する本追記は事後レビューであり、事前登録と称しない。
今後の新しいスコアについては、本追記を先にコミットしてから計測する。

既存の未追跡 `results/eval/memory/generation-outputs.json` は少数試行のメタデータを含む：
`rw` 20件、`fact` / `para` / `hyde` / `decomp` 各3件、合計32件。2026-10-12 14:03〜14:06 JSTに完了した記録がある。
従って厳密には「一切の生成開始前に本判断を済ませた」とは言えない。
今回は件数・時刻のメタデータだけを確認し、生成返答の内容や、それを使った新しい検索スコアは判断に使っていない。
既存の生成物と未追跡レビュー依頼を削除・変更せず、追加生成・再計測・本番用本文の閲覧も行わない。

本判断は分割の再作成ではなく、結論の範囲と追加報告方法の固定である。
`split.json`、`stages.json`、`generation.json`と既存結果のhashを記録し、凍結済みファイルは変更しない。
