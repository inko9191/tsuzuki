# J1：日本語でも記憶は効くか（事前登録）

状態：実行前に固定。計画 `results/eval/memory/j1-plan.json`（問題、データのハッシュ、モデル、コードのハッシュ）をコミットしてから回す。結果を見たあとで条件・判定は変えない。

## 問い

これまでの評価（U1、U2、U2-AT、E1）はすべて英語の LongMemEval だった。**日本語の会話でも、記憶（設定 P）は全文を読ませるより強いか。答える役が小さいモデル（Gemma 4 E2B）でも成り立つか。**

## テスト（自作、40 問）

日本語の長期記憶のテスト（会話の履歴と、それについての質問・正解の組）は、探した範囲では公開されていなかった（2026-10-24、Web 検索）。翻訳は時間がかかり、訳の正しさも保証しにくいので、自作する。

- **答えの入った会話**（`scripts/eval/j1/evidence_a.py`、`evidence_b.py`）：Claude が日本語で書いた。正解は作った時点で決まっている。種類は U2 にそろえた：1 回の会話の中の事実（ユーザー 6、アシスタント 4、好み 2）、情報の更新 8、日付の計算 8、複数の会話をまたぐ数え上げ 8、答えのない質問 4。日付の答えは計算で確かめた。
- **紛らわしい会話**（同じファイルの `near`）：友人の似た事実、読む予定だけの本、前の月の分、先々週末の分など。答えの会話ではない。
- **雑音の会話**（`build/eval/memory/j1/distractors.json`）：Gemma 4 E2B に 300 本書かせた一般的な日本語の雑談（料理、家電、観光、勉強法など）。ユーザーは自分についての事実を話さない指示なので、答えと食い違わない。
- **組み立て**（`scripts/eval/j1/build_dataset.py`）：1 問ごとに、答えの会話 + 紛らわしい会話 + 雑音 45 本（問題 ID で seed）を、質問日の前 180 日に散らして日付順に並べる。LongMemEval-S と同じ形式。
- **難しさの幅**：両方満点・両方 0 点にならないよう、簡単な問題（会話にそのまま書いてある事実）と難しい問題（日付の計算、数え上げ、途中で変わった情報、紛らわしい会話）を混ぜた。結果がそうなった場合は「床/天井」と明記する（正答率が 0.10 未満か 0.90 超）。

## 条件

- **E2B-P**：**全部 E2B**（小さいモデルだけで動かす構成）。U2 と同じ記憶の作り方（事実の抜き出しと更新リンク、EmbeddingGemma 300m、設定 P：枠 2048、密な順、日付つきの書式と質問日）で、事実の抜き出しと更新の判定も E2B が行い、その記憶を E2B が読んで答える（小さいモデルだけで動かすなら、記憶づくりも E2B がする）。プロンプトの規則は英語のまま（記憶の実装と同じ）。E1 は記憶を Qwen 27B が作っていたので、J1 が「全部 E2B」の最初の測定になる。
- **E2B-AT**：全文を同じ書式で E2B に渡す（窓 131072 に入る問）。

## 実行と採点

- E2B：E1 と同じファイル・同じサーバー引数。回答は U2 と同じ（1 問ずつ、`am.GENERATION`、JSON スキーマ）。
- 採点：U2 と同じ Qwen judge（英語の公式の種類別の基準を日本語の質問・正解・回答にそのまま使う）。副次の採点者として、Claude が条件名を伏せたシートで、Qwen の採点を開く前に採点する。

## 判定

区間は質問単位の対応ありブートストラップ（10000 回、seed 0）。

- **主：E2B-P − E2B-AT**（E2B-AT が窓に入った問）。下限 > 0 → 上回る。下限 ≥ −0.03 → 同等以上。上限 < 0 → 下回る。それ以外 → 判定不能。
- **Qwen での追試**：主判定が「上回る」か「同等以上」のときだけ、Qwen 27B で試す（ユーザーの指示）。追試は記憶づくりも答える役も Qwen にした構成で、別に事前登録する。
- 副：製品の目安（E2B-P ≥ 0.50）、種類別、棄権率、回答時間、P の記憶が答えの会話を全部含んだ割合。

## 限界

- 会話は Claude（答え）と E2B（雑音）が書いたもので、本物の利用者の会話より整っている。結果は「自作の日本語テスト」として報告する。
- 40 問なので大きな差しか見えない。英語の結果（E1）とは問題が違うので、数字を直接比べない（参考に並べるだけ）。
- 記憶の抜き出しと判定のプロンプトは英語のまま。
- 採点だけは Qwen 27B（U2 と同じ judge）。
